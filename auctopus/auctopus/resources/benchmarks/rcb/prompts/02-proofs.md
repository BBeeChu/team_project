You selected a proposal. Develop it into an analysis plan in this reply. Write, with headings:

1. Problem statement and notation.
2. Hypotheses H1, H2, ...: falsifiable statements about the data.
3. Method: the statistical or computational analysis for each hypothesis, step by step, naming the data files and columns or fields it uses.
4. Precommitted predictions: for each hypothesis, the quantity, the comparison, the threshold that counts as confirmation and the result that counts as refutation. Locked now.
5. Validation and controls: held-out checks, null models, permutation or bootstrap, sanity checks on the data; which control failures would make the result inconclusive.
6. Figures: the three to six figures the report must contain and what each shows.
