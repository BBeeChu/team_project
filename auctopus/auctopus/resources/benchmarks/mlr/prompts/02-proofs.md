You selected a proposal. Develop it into a research plan in this reply, in the same conversation. Write, with headings:

1. Problem statement: the question in one paragraph, with the notation you will use.
2. Method: the proposed method or analysis, stated precisely (equations or pseudocode where they help).
3. Hypotheses H1, H2, ...: each a falsifiable statement.
4. Precommitted predictions: for each hypothesis, the quantity to measure, the baseline, the threshold that counts as confirmation, and the result that counts as refutation. These are locked now and must be compared verbatim after the experiment.
5. Rival explanations and controls: what else could produce the predicted result, and which control run would separate it. State which control failures would make the experiment inconclusive.
6. Risks and the smallest version of the experiment that still tests H1.
